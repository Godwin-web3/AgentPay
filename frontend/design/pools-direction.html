Direction 02 — The thread

Everything is conversation. Objecting is the one thing that isn't.

A proposal reads like a message because it is one — but it carries a button no sentence can replace. That asymmetry is the whole safety model, so the interface should make it visible: soft bubbles for talk, one hard edge for the vote that actually moves money.
